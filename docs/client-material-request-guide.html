Accommodation Guide Production Kit

숙소 모바일 가이드
자료 요청서

고객이 이 문서만 따라 하면 숙소 모바일 가이드 제작에 필요한 정보와 사진을 빠짐없이 준비할 수 있습니다.

핵심 원칙

숙소 내부 정보는 고객이 제공하고, 공항 이동/대중교통/맛집/지도 링크는 AI가 초안을 보완한 뒤 고객이 최종 확인합니다.

진행 순서 필수 정보 AI 보완 사진 촬영 파일 정리 작성 양식 최종 검수

1. 진행 순서

기본 정보 작성

숙소명, 주소, 체크인/체크아웃, 연락처, 운영 규칙을 먼저 작성합니다.

사진 촬영

히어로, 객실, 입구, 도어락, 와이파이, 가전, 쓰레기 위치를 촬영합니다.

기존 자료 전달

에어비앤비 메시지, 노션, PDF, 안내문, 주변 맛집 리스트가 있으면 모두 전달합니다.

AI 보완 조사

공항 이동, 대중교통, 지도 링크, 주변 맛집, 주차장 후보를 AI가 조사합니다.

고객 확인

AI가 보완한 정보와 민감 정보 노출 범위를 고객이 확인합니다.

제작 및 배포

동일 템플릿에 내용과 사진만 교체해 모바일 가이드를 제작하고 배포합니다.

2. 고객에게 반드시 받아야 하는 정보

Basic숙소 기본 정보

숙소명, 주소, 층수, 인원, 체크인/아웃, 주차, 엘리베이터

Contact연락처

전화번호, 카카오톡, 긴급 연락 방식, 응대 가능 시간

Check-in입실 방법

도어락, 키번호 발송 시점, 입구 찾는 방법, 문제 발생 시 연락

Wi-Fi네트워크 정보

Wi-Fi 이름, 비밀번호, 공유기 위치, 연결 문제 조치

Rules숙소 규칙

금연, 방문자, 반려동물, 매너타임, 취사, 촬영, 파티

Facilities시설 사용법

TV, 온수, 난방, 세탁, 건조, 주방, 비품, 루프탑, 쓰레기

주의도어락 번호, 공동현관 비밀번호, CCTV 위치처럼 민감한 정보는 고객이 승인한 범위만 노출합니다.

3. AI가 보완할 수 있는 정보

항목AI 작업 가능 범위고객 확인
공항 이동인천공항/김포공항에서 숙소까지 대중교통, 리무진, 택시 경로 정리필수
대중교통가까운 역, 버스, 도보 구간, 환승 흐름 정리필수
지도 링크네이버 지도, 구글 지도 목적지 링크 생성필수
주변 맛집카테고리별 후보, 대표 메뉴, 지도 링크, 원본 출처 정리필수
주차장주변 유료 공영주차장 후보 조사필수
FAQ기존 메시지와 숙소 정보를 바탕으로 자주 묻는 질문 구성필수

4. 사진 촬영 가이드

공통 기준낮 시간 자연광, 원본 사진, 수평 유지, 필터 금지, 개인정보/비밀번호 노출 금지, 세로와 가로 사진 모두 촬영.
